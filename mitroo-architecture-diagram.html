Mitroo Architecture

Flutter Web · Node/Express/TypeScript · PostgreSQL + Redis · Docker Compose — Ε.Ε.Σ. asset & volunteer management

Client

  • • Flutter Web SPA, GoRouter + auth guard
  • • Provider/ChangeNotifier, one per domain
  • • PWA: install prompt, service worker
  • • Offline outbox for victim reports
  • • Socket.IO client + Web Push (VAPID)

Backend & Data

  • • Express + TypeScript, Zod validation
  • • JWT auth, admin guard, FHIR API-key path
  • • Socket.IO server, cron jobs (sync, cleanup)
  • • PostgreSQL 16 (Prisma) + Redis 7 (ioredis)
  • • AES-256-GCM for stored sync credentials

Integrations & Deployment

  • • SMTP (Nodemailer) — transactional email
  • • FHIR R4 import/export for external EHRs
  • • Legacy mitroo.redcross.gr sync (cookie/CSRF)
  • • Docker Compose: dev (DBs only) vs. prod (full stack)
  • • Nginx reverse-proxies /api/ → backend:4000
